---
description: Execute deployment with rollback plan.
---

1. 阅读 `.ai/skills/release/SKILL.md`。
2. 确认版本号和变更范围。
3. 执行 `.ai/hooks/before-release.md` 检查清单。
4. 按环境执行部署：
   - 测试环境：部署并运行冒烟测试。
   - 生产环境：灰度/全量发布，持续监控。
5. 验证服务健康状态。

## 回滚预案

1. 监控指标异常或核心功能失败时，立即触发回滚。
2. 回滚步骤：
   - 切换到上一版本镜像/构建产物。
   - 执行数据库反向迁移（如有）。
   - 验证服务恢复。
3. 通知相关人员，记录回滚原因。

## 检查项

- [ ] 版本号已确认。
- [ ] 变更日志已更新。
- [ ] 测试已全部通过。
- [ ] 环境配置已就绪。
- [ ] 部署已完成。
- [ ] 服务健康检查通过。
- [ ] 回滚预案已准备。
