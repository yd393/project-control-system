# test 命令

快速入口：运行测试并汇总结果。

## 触发方式

```text
/test [可选：测试范围或文件]
```

## 命令模板

```bash
# 运行全部测试
npm test
# 或
pytest

# 运行指定测试文件
npm test -- <path/to/test>
# 或
pytest <path/to/test>

# 生成覆盖率报告
npm run test:coverage
# 或
pytest --cov
```

## 结果解读

| 结果 | 含义 | 下一步 |
|------|------|--------|
| 全部通过 | 当前代码通过测试 | 继续后续流程 |
| 有失败 | 存在回归或新增缺陷 | 定位并修复 |
| 覆盖率下降 | 新增代码缺少测试 | 补充测试 |

## 输出格式

```markdown
## 测试汇总
- 总数：
- 通过：
- 失败：
- 跳过：
- 覆盖率：

## 失败用例
1. `<文件>:<行号>` - 错误信息

## 建议
- 
```
