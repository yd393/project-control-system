## 配置方式

1. 在 MCP 配置文件（如 `mcp.json`）中注册工具。
2. 配置认证信息（Token、API Key 等），禁止提交到代码库。
3. 启动服务后，AI 即可通过 MCP 调用工具。

## 安全说明

- 敏感凭证通过环境变量注入。
- 工具调用需记录审计日志。
- 限制工具的可访问范围，遵循最小权限原则。
