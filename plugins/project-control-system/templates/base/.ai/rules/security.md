# 安全规范

## 密钥管理

- 所有密钥、Token、密码必须存储在环境变量或专用密钥管理服务中。
- 禁止将密钥硬编码到源码、配置文件或日志中。
- 定期轮换生产环境密钥。
- 本地开发使用 `.env.example` 示例文件，不提交真实 `.env`。

## 权限控制

- 遵循最小权限原则。
- API 必须进行身份认证和授权校验。
- 敏感操作需要二次确认或审计日志。
- 禁止依赖前端隐藏来实现权限控制。

## 数据安全约束

- 用户密码必须使用强哈希算法（如 bcrypt、Argon2）。
- 敏感数据传输必须使用 TLS。
- 日志中不得包含密码、Token、信用卡号等敏感信息。
- 数据库字段需加密存储敏感个人信息。

## 常见漏洞防护

- 防范 SQL 注入：使用参数化查询或 ORM。
- 防范 XSS：输出编码，避免直接使用 `innerHTML`。
- 防范 CSRF：使用 CSRF Token 或 SameSite Cookie。
- 防范 SSRF：限制服务端可访问的外部地址。

## 依赖安全

- 定期扫描依赖漏洞。
- 及时升级存在严重漏洞的依赖。
- 禁止引入无维护、来源不明的依赖包。
