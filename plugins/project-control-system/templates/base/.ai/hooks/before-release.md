# 发布前检查清单

在发布前执行以下检查。

## 检查项

- [ ] **版本号**：已确认并更新 `package.json` / `pyproject.toml` 等版本号。
- [ ] **变更日志**：已更新 `CHANGELOG.md` 或发布说明。
- [ ] **Tag**：已创建版本 tag，如 `git tag v1.0.0`。
- [ ] **回归测试**：全量测试已通过。
- [ ] **文档**：用户文档和 API 文档已同步更新。
- [ ] **配置**：生产环境变量和配置已就绪。
- [ ] **数据库迁移**：迁移脚本已测试并可回滚。
- [ ] **依赖**：依赖版本已锁定，无已知严重漏洞。
- [ ] **监控**：日志、告警、指标采集已配置。

## 推荐命令

```bash
# 创建 tag
git tag -a v1.0.0 -m "Release v1.0.0"
git push origin v1.0.0

# 运行全量测试
npm test -- --coverage
# 或
pytest --cov
```

## 未通过处理

任何检查未通过时，禁止发布。问题解决后重新执行检查。
