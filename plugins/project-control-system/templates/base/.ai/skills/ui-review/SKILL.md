# ui-review 技能

## 何时使用

在完成前端页面或组件开发后，进行 UI 质量检查时使用。

## 执行步骤

1. **设计稿对照**：
   - 对照设计稿检查布局、颜色、字体、间距。
   - 确认图标、图片、动效是否符合预期。
2. **响应式检查**：
   - 在常见分辨率下测试（桌面、平板、手机）。
   - 检查横向滚动、元素溢出、断点切换。
3. **可访问性检查**：
   - 检查键盘导航是否完整。
   - 确认表单元素有正确的 label。
   - 检查颜色对比度是否足够。
   - 为图片和非文本内容添加合适的 alt 文本。
4. **交互检查**：
   - 验证按钮、链接、表单的交互反馈。
   - 检查加载、空态、错误态处理。
5. **一致性检查**：
   - 确认使用项目统一的组件库和设计 token。
   - 检查文案、术语、日期/货币格式一致性。
6. **性能检查**：
   - 检查图片懒加载、资源大小、渲染性能。
7. **输出报告**：
   - 汇总发现的问题，按严重程度和优先级分类。

## 验收标准

- [ ] 设计稿还原度达到要求。
- [ ] 主要分辨率下显示正常。
- [ ] 键盘可完整导航。
- [ ] 表单元素均有正确 label。
- [ ] 无明显颜色对比度问题。
- [ ] 交互反馈完整且一致。
- [ ] 问题清单已输出并跟踪。

## 注意事项

- 不要只在单一设备和浏览器下测试。
- 可访问性不仅是合规要求，也提升所有用户体验。
- 动效需适度，避免影响性能和可访问性。
