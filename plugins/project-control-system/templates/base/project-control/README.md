# Project Control 控制台

本目录是项目的总控入口，用于记录项目状态、计划、决策和交接信息。

## 文件说明

| 文件 | 用途 |
|------|------|
| `status.md` | 当前阶段、进度、阻塞项 |
| `roadmap.md` | 阶段目标与里程碑 |
| `backlog.md` | 待办任务与优先级 |
| `decisions.md` | 关键决策记录 |
| `handoff.md` | 模型/人员交接摘要 |

## 使用方式

1. 每次会话开始时先阅读 `status.md` 了解当前状态。
2. 根据任务类型查阅 `.ai/skills/<skill>/SKILL.md`。
3. 任务完成后更新 `status.md` 和 `backlog.md`。
